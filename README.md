# mitoleaf-rcrs

mitoLEAF (rCRS Human mtDNA) tree for HaploGrep 3.
Reference: Huber N, Hurmer N, Dür A, Parson W. NAR Genomics and Bioinformatics, 2025. https://doi.org/10.1093/nargab/lqaf079


## Create a Release

1. Increase the version in `tree.yaml` and commit it.
2. Create a release on GitHub and tag with the **same** version.
3. Register the new release by creating a pull request to
   [`trees.json`](https://github.com/genepi/haplogrep-trees/edit/main/trees.json),
   updating the entry to point at the new version.
